# Ames Housing Price Analysis

## Overview

This project performs exploratory data analysis on the Ames Housing dataset to understand the factors associated with residential property prices.

## Objectives

- Explore the housing dataset
- Understand numerical and categorical variables
- Handle missing values
- Calculate descriptive statistics
- Analyze house prices
- Study the relationship between price and living area
- Compare prices across neighborhoods
- Identify the strongest numerical predictors of SalePrice

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses the Ames Housing dataset.

The dataset contains information about residential properties including house size, quality, neighborhood, year built, number of rooms, garage information and sale price.
